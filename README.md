# Marlon Johnson — Developer Portfolio

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript. No build step is required.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy to Vercel

1. Create a GitHub repository and upload `index.html`, `styles.css`, `script.js`, and `README.md`.
2. In Vercel, import the repository.
3. Choose **Other** as the framework preset if prompted; no build command or output directory is needed for a static site.
4. Deploy.
